# Tools icons

Tools logos are local SVGs, with no third-party requests at runtime.

- OpenAI and Claude paths: Simple Icons v14.12.3, https://github.com/simple-icons/simple-icons/tree/14.12.3/icons (CC0). Claude uses its terracotta brand color.
- Figma: multicolor vector mark.
- Photoshop: navy Ps application tile.
- Codex: monochrome terminal tile, matching the portfolio hero reference.

Decorative emoji use Apple Color Emoji first, followed by native emoji fonts on other platforms. They are hidden from assistive technology; text labels remain readable and translatable. Apple styling depends on platform font availability.
